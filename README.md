# MLC4H<sup>2</sup>T

<div align="justify">
  
The extracted and summarized dataset of non-infected (NoI) and Trojan infected (TI1-TI8) features along with labels for different IP designs have been made publicly available by us here in GitHub. The description of different IP designs or benchmarks along with their transfer functions, data flow graphs (DFGs) are also available in the pdf file of this respository. \
This dataset consists of total 28 unique features (NoI and TI1-TI8), whose names are defined in the first row. Another 166 rows contain the instances of different NoI and TI1-TI8 IP designs. In the database, NoI instances are labeled as ‘0’, and Trojan infected (TI) instances are labeled as following: PD-HT (1), DoS-HT (2), BE-HT (3), DA-HT (4), F-HT (5), TB-HT (6), TST-HT (7), and T-HAC (8). \
However, the main motive of the proposed ML based detection approach is to present multi-label classification (i.e., non-infected or specific Trojan infected variance). Non-infected and Trojan infected IP designs are distributed across 18 instances and 148 instances respectively.
